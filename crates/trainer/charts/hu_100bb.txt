# Heads-up 100bb preflop charts (no rake).
#
# These are hand-written APPROXIMATIONS of solver strategies. The built-in
# heads-up charts use the solver charts in hu_100bb_solver.txt for the spots
# those cover (SB open, BB vs limp, BB vs open) and these for the rest.
# To use your own charts, point `charts_hu` in the config to a file in this
# format: its sections replace the built-in ones.
#
# Sections are keyed by the preflop line so far and the deciding position:
#   [SB:R BB:R>SB]  = SB opened, BB 3-bet, SB to act.
# Actions: R = raise (the menu's raise size), C = call/limp/check,
#   A = all-in, F = fold (only listed for players who had entered the pot).
#   [>SB] is the first decision (SB/button first to act).
# In each section list "allin:", "raise:" and "call:" ranges; weights are
# frequencies. Actions are applied in that order and each is capped by what
# is left; the remainder folds (or checks when folding isn't possible).
#
# Default menu: open 2.5bb, iso 3.5bb, 3-bet 3.5x, 4-bet 2.3x, then all-in.
